# Leveling System

## Overview

The leveling system in Prison RP - Project Hexa is experience-based, where players gain XP to progress through levels and unlock rewards.

## Experience Requirements

- **Level 0**: 50 XP to reach Level 1
- **Each subsequent level**: +50 XP
