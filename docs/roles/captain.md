# Captain

## Basic Info

- **Role Name**: Captain
- **Unlock Level**: 70
- **Status**: High-Ranking Authority

## Description

Captains lead the guard team. They organize patrols, give orders, and manage security in the absence of higher staff. They are responsible for maintaining overall order among guards.

## Spawn Equipment

- Tablet
- Walkie-talkie
- Baton
- Taser
- Handcuffs
- Flashlight
- Pistol

## Advantages

- Can dismiss the sergeant
