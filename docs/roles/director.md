# Director

## Basic Info

- **Role Name**: Director
- **Unlock Level**: 100
- **Status**: Supreme Authority

## Description

The highest authority in the prison. The Director manages all operations, staff, and rules. They oversee the entire prison system and make final decisions regarding security and organization.

## Spawn Equipment

- Megaphone
- Handcuffs
- Taser
- Bandages
- Flashlight
- Tablet
- Walkie-talkie
- Pistol (possibly)

## Advantages

- Supreme authority over all prison operations
- Full command and control
